title: WebSocket Gateway (@strafe-js/ws)
description: Persistent Stargate WebSocket client with opcodes 0-8, heartbeat tracking, and room subscription restoration.
---

`@strafe-js/ws` implements the **Stargate WebSocket Gateway protocol** (`wss://app.strafe.chat/gateway/events`) with automatic heartbeat timers (`op: 0`), `space_rooms` subscription hydration (`op: 1`), `SNAKE_CASE` to `camelCase` event normalization, and exponential backoff reconnection with random jitter.

## Standalone Usage

```ts title="src/gateway.ts"
import { Gateway } from '@strafe-js/ws';

const gateway = new Gateway({
  url: 'wss://app.strafe.chat/gateway/events',
  token: process.env.BOT_TOKEN!,
  heartbeatInterval: 25_000,
});

gateway.on('ready', (readyPayload) => {
  console.log(`Connected as ${readyPayload.user.username}`);
});

gateway.on('messageCreate', (message, envelope) => {
  console.log(`[${envelope.space_id}/${message.room_id}] ${message.plaintext}`);
});

gateway.on('sessionRevoked', ({ reason }) => {
  console.error(`Session revoked (${reason}); reconnection disabled.`);
});

gateway.connect();
```

## Gateway Opcodes (`GatewayOp`)

| Opcode | Name | Direction | Description |
| :--- | :--- | :--- | :--- |
| `0` | `Heartbeat` | Client -> Server | Periodic keep-alive frame sent every `heartbeatInterval` ms |
| `1` | `Subscribe` | Client -> Server | Subscribe to real-time events for `{ rooms, spaces }` |
| `2` | `Send` | Client -> Server | Client-to-server action frame |
| `3` | `Event` | Server -> Client | Dispatched event (`t`: event name, `d`: payload, `space_id`, `room_id`) |
| `4` | `Ready` | Server -> Client | Initial session state (`user`, `spaces`, `rooms`, `space_rooms`, `presences`) |
| `5` | `Unsubscribe` | Client -> Server | Unsubscribe from `{ rooms, spaces }` |
| `6` | `Ping` | Bidirectional | Application-level latency ping |
| `7` | `Pong` | Server -> Client | Response to `Heartbeat` (`op: 0`) or `Ping` (`op: 6`) |
| `8` | `Error` | Server -> Client | Gateway protocol or authentication error |

<Callout title="Nested and Flat op: 3 Envelopes" type="info">
  `@strafe-js/ws` normalizes both nested (`frame.d = { t, d, space_id, room_id }`) and flat (`frame = { op: 3, t, d, space_id, room_id }`) dispatch frames, and automatically copies `room_id` and `space_id` onto the payload object if omitted by the server.
</Callout>

  name="gateway.subscribe / gateway.unsubscribe"

    { name: 'opts.rooms', type: 'Snowflake[]', required: false, description: 'Room IDs to subscribe/unsubscribe.' },

  ]}
  example={`gateway.subscribe({ spaces: ['100'], rooms: ['200', '201'] });`}
/>
