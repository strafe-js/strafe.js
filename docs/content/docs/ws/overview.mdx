---
title: Gateway WebSocket SDK (@strafe-js/ws)
description: Real-time Stargate WebSocket Gateway client with automatic heartbeating, exponential backoff, and event normalization.
---

`@strafe-js/ws` manages persistent WebSocket connections to the Strafe Stargate Gateway (`wss://app.strafe.chat/gateway/events`). It automatically sends periodic `Ping` (`op: 6`) heartbeats, reconnects with jittered exponential backoff on network drops, supports both nested (`frame.d.t`) and flat (`frame.t`) `op: 3` event envelopes, and converts `SNAKE_CASE` gateway events into idiomatic `camelCase` Node `EventEmitter` events.

## Installation

```bash
npm install @strafe-js/ws @strafe-js/util
```

## Gateway Opcodes (`GatewayOp`)

| Opcode | Name | Direction | Description |
| :--- | :--- | :--- | :--- |
| `0` | `Heartbeat` | Client ↔ Server | Legacy heartbeat frame |
| `1` | `Subscribe` | Client → Server | Subscribe to real-time events for a `space_id` |
| `2` | `Send` | Client → Server | Send client action (e.g. `{ space_id: roomId, type: "typing" }`) |
| `3` | `Event` | Server → Client | Dispatched real-time event envelope (`t`, `space_id`, `room_id`, `d`) |
| `4` | `Ready` | Server → Client | Initial session handshake payload (`user`, `spaces`, `rooms`, `space_rooms`) |
| `5` | `Unsubscribe` | Client → Server | Unsubscribe from a `space_id` |
| `6` | `Ping` | Client → Server | Periodic heartbeat ping |
| `7` | `Pong` | Server → Client | Heartbeat acknowledgement |
| `8` | `Error` | Server → Client | Gateway-level error frame (`d.message`) |

## Standalone Gateway Example

```ts
import { Gateway } from '@strafe-js/ws';

const gateway = new Gateway({
  url: 'wss://app.strafe.chat/gateway/events',
  token: process.env.BOT_TOKEN!,
  heartbeatIntervalMs: 45_000,
  reconnect: true,
});

gateway.on('ready', (payload) => {
  console.log(`Connected as ${payload.user.username}`);
  for (const space of payload.spaces) {
    gateway.subscribe(space.id);
  }
});

gateway.on('messageCreate', (message) => {
  console.log(`[${message.room_id}] ${message.plaintext}`);
});

gateway.on('threadCreate', (thread) => {
  console.log(`New thread created: ${thread.name} (${thread.id})`);
});

gateway.connect();
```
