title: WebSocket Gateway (@strafe-js/ws)
description: Persistent Stargate WebSocket client with opcodes 0-8, heartbeat pings, and exponential backoff reconnection.
---

`@strafe-js/ws` implements the **Stargate WebSocket Gateway protocol** (`wss://app.strafe.chat/gateway/events`) with heartbeat timers (`op: 6`), `space_rooms` subscription frames (`op: 1`), `SNAKE_CASE` to `camelCase` event normalization, and exponential backoff reconnection with random jitter (`0..1000ms`).

## Standalone Usage

```ts title="src/gateway.ts"
import { Gateway } from '@strafe-js/ws';

const gateway = new Gateway({
  url: 'wss://app.strafe.chat/gateway/events',
  token: process.env.BOT_TOKEN!,
  heartbeatIntervalMs: 45_000,
});

gateway.on('ready', (readyPayload) => {
  console.log(`Connected as ${readyPayload.user.username}`);
  for (const space of readyPayload.spaces) {
    gateway.subscribe(space.id);
  }
});

gateway.on('messageCreate', (message, envelope) => {
  console.log(`[${envelope.space_id}/${message.room_id}] ${message.plaintext}`);
});

gateway.on('sessionRevoked', ({ reason }) => {
  console.error(`Session revoked (${reason}); reconnection disabled.`);
});

gateway.connect();
```

## Gateway Opcodes (`GatewayOp`)

| Opcode | Name | Direction | Description |
| :--- | :--- | :--- | :--- |
| `0` | `Heartbeat` | Bidirectional | Legacy heartbeat frame |
| `1` | `Subscribe` | Client -> Server | Subscribe to real-time events for `{ space_id }` |
| `2` | `Send` | Client -> Server | Client-to-server action frame (such as `typing`) |
| `3` | `Event` | Server -> Client | Dispatched event (`t`: event name, `d`: payload, `space_id`, `room_id`) |
| `4` | `Ready` | Server -> Client | Initial session state (`user`, `spaces`, `rooms`, `space_rooms`) |
| `5` | `Unsubscribe` | Client -> Server | Unsubscribe from `{ space_id }` |
| `6` | `Ping` | Client -> Server | Periodic heartbeat ping sent every `heartbeatIntervalMs` |
| `7` | `Pong` | Server -> Client | Response to `Ping` (`op: 6`) |
| `8` | `Error` | Server -> Client | Gateway protocol or authentication error |

<Callout title="Nested and Flat op: 3 Envelopes" type="info">
  `@strafe-js/ws` normalizes both nested (`frame.d = { t, d, space_id, room_id }`) and flat (`frame = { op: 3, t, d, space_id, room_id }`) dispatch frames, and copies `room_id` and `space_id` onto the payload object when omitted by the server.
</Callout>

## Gateway Methods

<MethodCard
  name="gateway.connect"
  signature="() => void"
  returnType="void"
  isAsync={false}
  description="Opens the WebSocket connection to url with the configured Authorization header and starts the heartbeat timer once the socket opens."
  example={`gateway.connect();`}
/>

<MethodCard
  name="gateway.subscribe / gateway.unsubscribe"
  signature="(spaceOrRoomId: Snowflake) => void"
  returnType="void"
  isAsync={false}
  description="Subscribes (op: 1) or unsubscribes (op: 5) from real-time events for a space or room ID."
  parameters={[
    { name: 'spaceOrRoomId', type: 'Snowflake', required: true, description: 'Space or Room Snowflake ID to subscribe or unsubscribe.' },
  ]}
  example={`gateway.subscribe('987654321098765432');`}
/>

<MethodCard
  name="gateway.ping"
  signature="() => void"
  returnType="void"
  isAsync={false}
  description="Sends a Ping (op: 6) frame to the Gateway. The Gateway responds with Pong (op: 7)."
  example={`gateway.ping();`}
/>

<MethodCard
  name="gateway.disconnect"
  signature="() => void"
  returnType="void"
  isAsync={false}
  description="Disables automatic reconnection, clears active heartbeat and reconnect timers, and closes the WebSocket connection with code 1000."
  example={`gateway.disconnect();`}
/>
