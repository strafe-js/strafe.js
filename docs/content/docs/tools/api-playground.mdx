Select a `@strafe-js/rest` method or `@strafe-js/ws` Gateway opcode below to inspect the TypeScript SDK call and JSON payload. Switch to **Use Own Token (Live)** to execute direct client-side requests against a Strafe API instance using your own Bot or Bearer token. Provided credentials remain exclusively in volatile browser memory (`React.useState`) and are never stored in `localStorage`, `sessionStorage`, cookies, or external logs.
