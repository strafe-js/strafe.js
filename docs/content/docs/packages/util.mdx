`@strafe-js/util` is the foundational zero-dependency package of the Strafe.js ecosystem. It defines all shared TypeScript interfaces, `Permission` bitflags, `BitField`, `RoomType`, `GatewayOp`, `StrafeError`, and `RateLimitError`.

## Installation

```bash
npm install @strafe-js/util
```

## `BitField` Class

`BitField` wraps a 32-bit numeric permission mask and provides ergonomic methods for inspecting and mutating permissions.

  name="new BitField"

  parameters={[

  ]}
  example={`const bits = new BitField(['ViewRoom', 'SendMessages']);`}
/>

<MethodCard
  name="bitField.has"
  signature="(perm: PermissionResolvable) => boolean"
  returnType="boolean"
  isAsync={false}
  description="Returns true if all specified permission bits are set in the bitfield."
  parameters={[
    { name: 'perm', type: 'PermissionResolvable', required: true, description: 'Permission name, bitmask, or array to check.' },
  ]}
  example={`if (bits.has(['ViewRoom', 'SendMessages'])) {\n  // Allowed\n}`}
/>

<MethodCard
  name="bitField.add / bitField.remove"
  signature="(...perms: PermissionResolvable[]) => this"
  returnType="BitField"
  isAsync={false}
  description="Mutates the BitField by adding (|=) or removing (&= ~) the specified permissions."
  parameters={[
    { name: '...perms', type: 'PermissionResolvable[]', required: true, description: 'Permissions to add or remove.' },
  ]}
  example={`bits.add('EmbedLinks', 'AttachFiles');\nbits.remove('AttachFiles');`}
/>

<MethodCard
  name="bitField.toArray"
  signature="() => PermissionName[]"
  returnType="PermissionName[]"
  isAsync={false}
  description="Returns an array of all active PermissionName strings in this BitField."
  example={`console.log(bits.toArray()); // ['ViewRoom', 'SendMessages', 'EmbedLinks']`}
/>

## Constants: `RoomType` & `GatewayOp`

```ts
import { RoomType, GatewayOp } from '@strafe-js/util';

// RoomType values:
// PM = 1, GroupPM = 2, Text = 3, Voice = 4, Section = 5, Thread = 6

// GatewayOp values:
// Heartbeat = 0, Subscribe = 1, Send = 2, Event = 3, Ready = 4,
// Unsubscribe = 5, Ping = 6, Pong = 7, Error = 8
```
