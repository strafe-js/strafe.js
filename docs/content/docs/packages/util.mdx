`@strafe-js/util` is the foundational zero-dependency package of the Strafe.js ecosystem. It defines all shared TypeScript interfaces, the official 28-bit `Permission` bitflags, `BitField`, `RoomType`, `GatewayOp`, `StrafeError`, and `RateLimitError`.

## Installation

```bash title="Terminal"
npm install @strafe-js/util
```

## `BitField` Class

`BitField` wraps a 32-bit numeric permission mask and provides ergonomic methods for inspecting and mutating permissions.

<MethodCard

  example={`if (bits.has(['ViewRoom', 'SendMessages'])) {\n  // Allowed\n}`}
