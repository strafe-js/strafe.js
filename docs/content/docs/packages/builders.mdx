`@strafe-js/builders` provides chainable builders for constructing `CreateMessageBody` payloads, room permission overrides (`PermissionOverride`), and OAuth2 authorization URLs.

## Installation

```bash title="Terminal"
npm install @strafe-js/builders @strafe-js/util
```

## Example Usage

```ts title="src/builders.ts"
import { message, permissions, permissionMask } from '@strafe-js/builders';

const payload = message()
  .setContent('Welcome to the space. Please read the rules.')
  .setReply('112233445566778899')
  .setMentions(['223344556677889900'])
  .setRoleMentions(['334455667788990011'])
  .mentionEveryone(false)
  .setAttachments(['445566778899001122'])
  .toJSON();

await client.rest.createMessage(roomId, payload);

const modMask = permissions(['KickMembers', 'BanMembers', 'ManageMessages']);
const combinedMask = permissionMask('ViewRoom', 'SendMessages', modMask);
```

## `PermissionOverwriteBuilder` Reference
