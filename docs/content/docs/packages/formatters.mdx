title: "@strafe-js/formatters"

---

`@strafe-js/formatters` provides pure helper functions for formatting mentions, custom emojis, and escaping user-supplied Markdown characters in Strafe Chat messages.

## Installation

```bash
npm install @strafe-js/formatters @strafe-js/util
```

## Quick Example

```ts
import {
  userMention,
  roleMention,
  roomMention,
  customEmoji,
  escapeMarkdown,
} from '@strafe-js/formatters';

const msg = [
  `Welcome ${userMention('123456789012345678')}!`,
  `Check out ${roomMention('234567890123456789')} and ping ${roleMention('345678901234567890')}.`,
  `Reaction: ${customEmoji('party', '456789012345678901', true)}`,
  `Escaped nickname: ${escapeMarkdown('**Admin_User**')}`,
].join('\n');
```
