## `@strafe-js/builders`

Fluent builders for constructing API payloads and permission bitmasks.

```ts
import { message, permissions } from '@strafe-js/builders';

const payload = message()
  .setContent('Hello from MessageBuilder!')
  .setReply('112233445566778899')
  .mentionEveryone(false)
  .toJSON();

const modMask = permissions(['KickMembers', 'BanMembers', 'ManageMessages']);
```

## `@strafe-js/formatters`

Formatting utilities for mentions, custom emojis, and Markdown escaping:

```ts
import {
  userMention,
  roleMention,
  roomMention,
  customEmoji,
  escapeMarkdown,
} from '@strafe-js/formatters';

userMention('123456789012345678'); // "<@123456789012345678>"
roleMention('123456789012345678'); // "<@&123456789012345678>"
roomMention('123456789012345678'); // "<#123456789012345678>"
customEmoji('party', '998877665544332211', true); // "<a:party:998877665544332211>"
escapeMarkdown('**bold_text**'); // "\\*\\*bold\\_text\\*\\*"
```

## `@strafe-js/collection`

`Collection<K, V>` extends JavaScript's native `Map<K, V>` with array-like functional methods:

```ts
import { Collection } from '@strafe-js/collection';

const cache = new Collection<string, { id: string; online: boolean }>();
cache.set('1', { id: '1', online: true });
cache.set('2', { id: '2', online: false });

const firstOnline = cache.find((u) => u.online);
const onlineCollection = cache.filter((u) => u.online);
const allIds = cache.map((u) => u.id);
```

## `@strafe-js/util`

Provides shared TypeScript models, `Permission` flags, `BitField`, `StrafeError`, `RateLimitError`, and `isSnowflake()`:

```ts
import { BitField, Permission, isSnowflake } from '@strafe-js/util';

const bits = new BitField(Permission.ViewRoom | Permission.SendMessages);
console.log(bits.has('SendMessages')); // true
console.log(bits.toArray()); // ['ViewRoom', 'SendMessages']
console.log(isSnowflake('123456789012345678')); // true
```
