Beyond the main `@strafe-js/strafebot` client, `@strafe-js/rest`, and `@strafe-js/ws`, the Strafe.js monorepo provides 4 focused utility packages that can be used either alongside `strafebot` or standalone in any Node.js/TypeScript environment.

<Cards>
  <Card
    title="@strafe-js/builders"
    href="/docs/packages/builders"
    description="Fluent MessageBuilder and permission bitmask factories (message, permissions, permissionMask)."
  />
  <Card
    title="@strafe-js/formatters"
    href="/docs/packages/formatters"
    description="Mentions (<@id>, <@&id>, <#id>), static/animated custom emojis, and Markdown escaping."
  />
  <Card
    title="@strafe-js/collection"
    href="/docs/packages/collection"
    description="Zero-dependency Map<K, V> subclass with functional query methods (find, filter, map, first)."
  />
  <Card
    title="@strafe-js/util"
    href="/docs/packages/util"
    description="Core TypeScript API models, 28 Permission bitflags, BitField class, StrafeError, and RateLimitError."
  />
</Cards>

## Package Dependency Matrix

| Package | Version | Internal Dependencies | External Dependencies | Re-exported by `@strafe-js/strafebot`? |
| :--- | :--- | :--- | :--- | :--- |
| `@strafe-js/util` | `1.0.5` | None | None | Yes |
| `@strafe-js/collection` | `1.0.5` | None | None | Yes |
| `@strafe-js/formatters` | `1.0.5` | `@strafe-js/util` | None | No (install or import directly) |
| `@strafe-js/builders` | `1.0.5` | `@strafe-js/util` | None | No (install or import directly) |
| `@strafe-js/rest` | `1.0.5` | `@strafe-js/util` | None | Yes |
| `@strafe-js/ws` | `1.0.5` | `@strafe-js/util` | `ws` | Yes |

## Installing All Ecosystem Packages

```bash
npm install @strafe-js/strafebot @strafe-js/builders @strafe-js/formatters @strafe-js/collection @strafe-js/util
```
