Alongside `@strafe-js/strafebot`, `@strafe-js/rest`, and `@strafe-js/ws`, the Strafe.js monorepo provides 4 focused packages that are re-exported by `@strafe-js/strafebot` and can also be installed standalone:

<Cards>
  <Card
    title="@strafe-js/builders"
    href="/docs/packages/builders"
    description="MessageBuilder, PermissionOverwriteBuilder, bitmask helpers, and OAuth2 URL builders."
  />
  <Card
    title="@strafe-js/formatters"
    href="/docs/packages/formatters"
    description="Mentions (<@id>, <@&id>, <#id>), custom emoji tags, and Markdown escaping."
  />
  <Card
    title="@strafe-js/collection"
    href="/docs/packages/collection"
    description="Zero-dependency Map<K, V> subclass with find, filter, map, first, last, random, partition, and sweep."
  />
  <Card
    title="@strafe-js/util"
    href="/docs/packages/util"
    description="Shared TypeScript API models, 28 Permission bitflags, BitField class, StrafeError, and RateLimitError."
  />
</Cards>

## Package Dependency Matrix

| Package | Version | Internal Dependencies | External Dependencies | Re-exported by `@strafe-js/strafebot`? |
| :--- | :--- | :--- | :--- | :--- |
| `@strafe-js/util` | <SdkVersion pkg="@strafe-js/util" code /> | None | None | Yes |
| `@strafe-js/collection` | <SdkVersion pkg="@strafe-js/collection" code /> | None | None | Yes |
| `@strafe-js/formatters` | <SdkVersion pkg="@strafe-js/formatters" code /> | `@strafe-js/util` | None | Yes |
| `@strafe-js/builders` | <SdkVersion pkg="@strafe-js/builders" code /> | `@strafe-js/util` | None | Yes |
| `@strafe-js/rest` | <SdkVersion pkg="@strafe-js/rest" code /> | `@strafe-js/util` | None | Yes |
| `@strafe-js/ws` | <SdkVersion pkg="@strafe-js/ws" code /> | `@strafe-js/util` | `ws` | Yes |
| `@strafe-js/strafebot` | <SdkVersion pkg="@strafe-js/strafebot" code /> | All 6 `@strafe-js/*` packages | None | Main SDK entry point |
| `create-strafebot` | <SdkVersion pkg="create-strafebot" code /> | Scaffolds `@strafe-js/strafebot` | None | Standalone CLI |

## Installing All Ecosystem Packages

```bash title="Terminal"
npm install @strafe-js/strafebot @strafe-js/builders @strafe-js/formatters @strafe-js/collection @strafe-js/util
```
