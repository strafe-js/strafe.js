---

`@strafe-js/collection` provides `Collection<K, V>`, an enhanced subclass of JavaScript's built-in `Map<K, V>` that adds array-like functional query and transformation methods. All entity caches on `Client` (`client.spaces`, `client.rooms`, `client.spaceRooms`, `client.members`) are instances of `Collection`.

## Installation

```bash title="Terminal"
npm install @strafe-js/collection
```

> Note: `Collection` is also re-exported directly from `@strafe-js/strafebot`.

## Quick Example

```ts title="src/collection.ts"
import { Collection } from '@strafe-js/collection';

interface MemberInfo {
  id: string;
  username: string;
  roles: string[];
}

const members = new Collection<string, MemberInfo>();
members.set('1', { id: '1', username: 'alice', roles: ['admin', 'mod'] });
members.set('2', { id: '2', username: 'bob', roles: ['mod'] });
members.set('3', { id: '3', username: 'charlie', roles: [] });

const admin = members.find((m) => m.roles.includes('admin'));
const moderators = members.filter((m) => m.roles.includes('mod'));
const usernames = members.map((m) => m.username); // ['alice', 'bob', 'charlie']
```
