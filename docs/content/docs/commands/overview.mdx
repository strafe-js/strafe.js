`@strafe-js/strafebot` includes a first-class command framework powered by `CommandHandler`, `Command`, `Context`, and `CommandArgument`.

## Defining a Command

Use the `command()` helper to define commands with full TypeScript inference for parsed arguments:

```ts title="src/commands/roll.ts"
import { command } from '@strafe-js/strafebot';

export const rollCommand = command({
  name: 'roll',
  aliases: ['dice'],
  description: 'Roll a dice with custom sides',
  cooldown: 3000,
  arguments: {
    sides: {
      type: 'integer',
      min: 2,
      max: 1000,
      default: 6,
      description: 'Number of sides on the die',
    },
  },
  async run(ctx) {
    const sides = ctx.arguments.get('sides'); // inferred as number
    const result = Math.floor(Math.random() * sides) + 1;
    await ctx.reply(`🎲 You rolled **${result}** (1-${sides})`);
  },
});
```

## Supported Argument Schema Types

| Type | Parsed TypeScript Type | Validation & Features |
| :--- | :--- | :--- |
| `'string'` | `string` | Supports `min` / `max` length, `choices`, and `rest: true` (captures remaining tokens) |
| `'integer'` | `number` | Rejects decimals; supports `min` / `max` numeric bounds and `choices` |
| `'number'` | `number` | Floating-point or integer numbers; supports `min` / `max` bounds and `choices` |
| `'boolean'` | `boolean` | Accepts `true/false`, `yes/no`, `1/0`, `on/off` |
| `'user'` | `Snowflake` | Accepts raw 16-20 digit Snowflake IDs or `<@id>` / `<@!id>` user mentions |
| `'snowflake'` | `Snowflake` | Validates 16-20 digit Snowflake IDs |
| `'attachment'` | `Attachment` | Consumes uploaded message attachments from `message.attachments` |

## Command Guard Events

`CommandHandler` emits lifecycle and guard rejection events on `Client`:

- `commandPermissionDenied`: `(ctx, command)` - Caller lacks required `permissions`
- `commandBotPermissionDenied`: `(ctx, command, missingBitField)` - Bot lacks required `botPermissions`
- `commandCooldown`: `(ctx, command, remainingMs)` - User is on cooldown
- `commandInvalidArguments`: `(ctx, command, error)` - Schema or `minArgs`/`maxArgs` validation failed
- `commandError`: `(error, ctx, command)` - Unhandled error thrown inside `command.run(ctx)`
