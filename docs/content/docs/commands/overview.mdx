`@strafe-js/strafebot` includes a prefix command dispatcher built from `CommandHandler`, `Command`, `Context`, and `CommandArgument`.

## Defining a Command

Use the `command()` factory to define commands with TypeScript inference for parsed arguments:

```ts title="src/commands/roll.ts"
import { command } from '@strafe-js/strafebot';

export const rollCommand = command({
  name: 'roll',
  aliases: ['dice'],
  description: 'Roll a die with custom sides',
  cooldown: 3000,
  arguments: {
    sides: {
      type: 'integer',
      min: 2,
      max: 1000,
      default: 6,
      description: 'Number of sides on the die',
    },
  },
  async run(ctx) {
    const sides = ctx.arguments.get('sides'); // inferred as number
    const result = Math.floor(Math.random() * sides) + 1;
    await ctx.reply(`Rolled **${result}** (1-${sides})`);
  },
});
```

## Supported Argument Schema Types

| Type | Parsed TypeScript Type | Validation & Features |
| :--- | :--- | :--- |
| `'string'` | `string` | Supports `minLength` / `maxLength`, `choices`, and `rest: true` (joins remaining tokens) |
| `'integer'` | `number` | Rejects decimals; supports `min` / `max` numeric bounds and `choices` |
| `'number'` | `number` | Floating-point or integer numbers; supports `min` / `max` bounds and `choices` |
| `'boolean'` | `boolean` | Accepts `true/false`, `yes/no`, `1/0`, `y/n` |
| `'user'` | `Snowflake` | Extracts IDs from `<@id>` / `<@!id>` user mentions or passes a raw ID string |
| `'room'` | `Snowflake` | Accepts 16-20 digit Snowflake IDs or `<#id>` room mentions |
| `'role'` | `Snowflake` | Accepts 16-20 digit Snowflake IDs or `<@&id>` role mentions |
| `'snowflake'` | `Snowflake` | Extracts 16-20 digit Snowflake IDs from `<@id>`, `<#id>`, `<@&id>`, or raw strings |
| `'attachment'` | `Attachment` | Consumes `message.attachments[0]` without advancing the text token cursor |

## Built-In Help Command & Middleware

Register a category-grouped `!help [command]` command with `createHelpCommand()` and attach pre-execution hooks via `client.commands.use()`:

```ts title="src/index.ts"
import { createHelpCommand } from '@strafe-js/strafebot';

client.commands.use(async (ctx, next) => {
  console.log(`[CMD] ${ctx.commandName} by ${ctx.authorId}`);
  await next();
});

client.commands.register(
  createHelpCommand({ title: '**Bot Commands**' }),
);
```

## Command Lifecycle Events

`CommandHandler` emits lifecycle events on `Client`:

- `commandCooldown`: `(remainingMs: number, message: Message, command: Command)` - Caller is on per-user cooldown.
- `commandArgumentError`: `(error: ArgumentValidationError, message: Message, command: Command)` - Schema validation failed.
- `commandError`: `(error: unknown, ctx: Context)` - Unhandled exception thrown inside `command.run(ctx)`.
