`@strafe-js/strafebot` provides a powerful argument parsing pipeline (`tokenizeArguments` and `parseAndValidateArguments`) that transforms raw chat messages into strongly-typed TypeScript values.

## 1. Quote-Aware Tokenization (`tokenizeArguments`)

When a command message is received, `tokenizeArguments(input)` splits the argument string by whitespace while preserving double-quoted phrases and backslash escapes:

```ts title="src/tokenizer.ts"
import { tokenizeArguments } from '@strafe-js/strafebot';

tokenizeArguments('123456789012345678 "Spamming in #general" --silent');
// -> ['123456789012345678', 'Spamming in #general', '--silent']
```

## 3. Complete Schema Example

```ts title="src/commands/timeout.ts"
import { command } from '@strafe-js/strafebot';

export const timeoutCommand = command({
  name: 'timeout',
  guildOnly: true,
  permissions: ['KickMembers'],
  botPermissions: ['KickMembers'],
  arguments: {
    target: {
      type: 'user',
      required: true,
      description: 'Member to timeout (@mention or ID)',
    },
    durationMinutes: {
      type: 'integer',
      min: 1,
      max: 10080,
      default: 60,
      description: 'Duration in minutes (1m to 7d)',
    },
    unit: {
      type: 'string',
      choices: ['m', 'h', 'd'] as const,
      default: 'm',
    },
    silent: {
      type: 'boolean',
      default: false,
    },
    reason: {
      type: 'string',
      rest: true,
      default: 'No reason specified',
    },
  },
  async run(ctx) {
    const target = ctx.arguments.get('target');           // Snowflake
    const duration = ctx.arguments.get('durationMinutes'); // number
    const unit = ctx.arguments.get('unit');               // string
    const silent = ctx.arguments.get('silent');           // boolean
    const reason = ctx.arguments.get('reason');           // string

    await ctx.reply(
      `Timed out <@${target}> for ${duration}${unit} (silent=${silent}): ${reason}`
    );
  },
});
```

## 4. Handling `ArgumentValidationError`

When an argument fails validation, `parseAndValidateArguments` throws an `ArgumentValidationError` with structured diagnostic fields (`argName`, `reason`, `expectedType`, `received`):

```ts title="src/index.ts"
import { ArgumentValidationError } from '@strafe-js/strafebot';

client.on('commandInvalidArguments', async (ctx, cmd, err) => {
  if (err instanceof ArgumentValidationError) {
    await ctx.reply(
      `⚠️ Invalid argument \`${err.argName}\` (${err.reason}): ${err.message}`
    );
  } else {
    await ctx.reply(`⚠️ ${err.message}`);
  }
});
```
