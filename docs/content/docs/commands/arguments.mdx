`@strafe-js/strafebot` parses and validates command arguments using `tokenizeArguments` and `parseAndValidateArguments`.

## 1. Quote-Aware Tokenization (`tokenizeArguments`)

When a command message is received, `tokenizeArguments(input)` splits the argument string by whitespace while preserving double-quoted phrases and backslash escapes:

```ts title="src/tokenizer.ts"
import { tokenizeArguments } from '@strafe-js/strafebot';

tokenizeArguments('123456789012345678 "Spamming in #general" --silent');
// -> ['123456789012345678', 'Spamming in #general', '--silent']
```

## 3. Schema Example

```ts title="src/commands/timeout.ts"
import { command } from '@strafe-js/strafebot';

export const timeoutCommand = command({
  name: 'timeout',
  guildOnly: true,
  permissions: ['KickMembers'],
  botPermissions: ['KickMembers'],
  arguments: {
    target: {
      type: 'user',
      required: true,
      description: 'Member to timeout (@mention or ID)',
    },
    durationMinutes: {
      type: 'integer',
      min: 1,
      max: 10080,
      default: 60,
      description: 'Duration in minutes (1m to 7d)',
    },
    unit: {
      type: 'string',
      choices: ['m', 'h', 'd'],
      default: 'm',
    },
    silent: {
      type: 'boolean',
      default: false,
    },
    reason: {
      type: 'string',
      rest: true,
      default: 'No reason specified',
    },
  },
  async run(ctx) {
    const target = ctx.arguments.get('target');
    const duration = ctx.arguments.get('durationMinutes');
    const unit = ctx.arguments.get('unit');
    const silent = ctx.arguments.get('silent');
    const reason = ctx.arguments.get('reason');

    await ctx.reply(
      `Timed out <@${target}> for ${duration}${unit} (silent=${silent}): ${reason}`,
    );
  },
});
```

## 4. Handling `ArgumentValidationError`

When an argument fails validation, `parseAndValidateArguments` throws an `ArgumentValidationError` containing `argumentName`, `code` (`'REQUIRED' | 'INVALID_TYPE' | 'INVALID_CHOICE' | 'OUT_OF_RANGE' | 'INVALID_ATTACHMENT'`), `expected`, and `value`. `CommandHandler` replies to the caller and emits `commandArgumentError`:

```ts title="src/index.ts"
import { ArgumentValidationError } from '@strafe-js/strafebot';

client.on('commandArgumentError', (err, msg, cmd) => {
  if (err instanceof ArgumentValidationError) {
    console.warn(
      `Command !${cmd.name} failed on ${err.argumentName} (${err.code}): expected ${err.expected}, got ${String(err.value)}`,
    );
  }
});
```
