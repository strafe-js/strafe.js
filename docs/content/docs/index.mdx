**Strafe.js** is a TypeScript monorepo for building bots, OAuth2 integrations, and real-time clients on **Strafe Chat** (`https://app.strafe.chat`).

## Ecosystem Architecture

Strafe.js is organized as a layered monorepo so you can install the `@strafe-js/strafebot` framework or consume individual packages directly:

| Package | Responsibility | Runtime Dependencies |
| :--- | :--- | :--- |
| `@strafe-js/strafebot` | Bot `Client`, state caches, Equinox permission resolver, and `CommandHandler` | `@strafe-js/*` |
| `@strafe-js/rest` | HTTP REST client with automatic `429 Retry-After` backoff, OAuth2, and `FormData` uploads | `@strafe-js/util` |
| `@strafe-js/ws` | Persistent Stargate WebSocket Gateway client with heartbeating and exponential jitter backoff | `@strafe-js/util`, `ws` |
| `@strafe-js/builders` | `MessageBuilder`, `PermissionOverwriteBuilder`, bitmask helpers, and OAuth2 URL generators | `@strafe-js/util` |
| `@strafe-js/formatters` | Mention (`<@id>`, `<@&id>`, `<#id>`), custom emoji, and Markdown escaping helpers | `@strafe-js/util` |
| `@strafe-js/collection` | `Map<K, V>` subclass with query and transformation methods (`find`, `filter`, `map`, `sweep`) | None |
| `@strafe-js/util` | Shared TypeScript interfaces, `Permission` flags, `BitField`, E2EE helpers, and error classes | None |
| `create-strafebot` | CLI scaffolder for new bot projects and `src/commands/<name>.ts` modules | Node.js built-ins |

## Minimal Bot Example

```ts title="src/index.ts"
import { Client, command } from '@strafe-js/strafebot';

const client = new Client({
  apiBase: 'https://app.strafe.chat/api',
  gatewayUrl: 'wss://app.strafe.chat/gateway/events',
  prefix: '!',
});

client.on('ready', (data) => {
  console.log(`Logged in as ${data.user.username} (${data.spaces.length} spaces)`);
  console.log(
    'Invite URL:',
    client.generateInviteUrl({
      permissions: ['ViewRoom', 'SendMessages', 'ReadMessageHistory'],
    }),
  );
});

client.commands.register(
  command({
    name: 'ping',
    description: 'Check bot latency',
    async run(ctx) {
      await ctx.reply('Pong!');
    },
  }),
);

await client.login(process.env.BOT_TOKEN!);
```
