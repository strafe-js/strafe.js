Welcome to the official **Strafe.js** documentation. Strafe.js is a modular, strictly-typed TypeScript monorepo for building bots, OAuth2 integrations, and real-time clients on **Strafe Chat** (`https://app.strafe.chat`).

## Ecosystem Architecture

Strafe.js is organized as a layered monorepo so you can install the all-in-one `@strafe-js/strafebot` framework or consume low-level packages individually:

| Package | Description | Runtime Dependencies |
| :--- | :--- | :--- |
| `@strafe-js/strafebot` | High-level Bot `Client`, state caches, Equinox permission engine, and `CommandHandler` | `@strafe-js/*` |
| `@strafe-js/rest` | HTTP REST client with automatic `429 Retry-After` backoff, OAuth2, and `FormData` uploads | `@strafe-js/util` |
| `@strafe-js/ws` | Persistent Stargate WebSocket Gateway client with heartbeating and exponential jitter backoff | `@strafe-js/util`, `ws` |
| `@strafe-js/builders` | Fluent `MessageBuilder`, permission bitmask helpers, and OAuth2 URL generators | `@strafe-js/util` |
| `@strafe-js/formatters` | Mention (`<@id>`, `<@&id>`, `<#id>`), custom emoji, and Markdown escaping helpers | `@strafe-js/util` |
| `@strafe-js/collection` | Extended `Map<K, V>` subclass with functional query methods (`find`, `filter`, `map`) | None |
| `@strafe-js/util` | Core TypeScript interfaces, `Permission` flags, `BitField`, E2EE helpers, and error classes | None |
| `create-strafebot` | Interactive CLI tool to scaffold new bot projects and generate command files | Node.js built-ins |

## Minimal Example

```ts title="src/index.ts"
import { Client, command } from '@strafe-js/strafebot';

const client = new Client({
  apiBase: 'https://app.strafe.chat/api',
  gatewayUrl: 'wss://app.strafe.chat/gateway/events',
  prefix: '!',
});

client.on('ready', (data) => {
  console.log(`Logged in as ${data.user.username} (${data.spaces.length} spaces)`);
  console.log(
    'Invite URL:',
    client.generateInviteUrl({
      permissions: ['ViewRoom', 'SendMessages', 'ReadMessageHistory'],
    }),
  );
});

client.commands.register(
  command({
    name: 'ping',
    description: 'Check bot responsiveness',
    async run(ctx) {
      await ctx.reply('Pong! 🏓');
    },
  }),
);

await client.login(process.env.BOT_TOKEN!);
```
