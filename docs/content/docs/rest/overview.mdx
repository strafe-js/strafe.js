`@strafe-js/rest` provides the `REST` class for interacting with the Strafe HTTP API. It is exposed as `client.rest` on `@strafe-js/strafebot` or can be instantiated standalone.

## Standalone Usage

```ts
import { REST } from '@strafe-js/rest';

const rest = new REST({
  baseUrl: 'https://app.strafe.chat/api',
  token: process.env.BOT_TOKEN,
  authScheme: 'Bot',
  retries: 3,
});

const me = await rest.getMe();
console.log(`Authenticated as ${me.username}`);
```

## Automatic Rate-Limit Handling

When the Strafe API responds with `HTTP 429 Too Many Requests`, `REST.request()` automatically reads `retry_after` from the JSON response body (or the `Retry-After` HTTP header), sleeps for the required duration, and retries the request up to `retries` times (default `3`). If retries are exhausted, a `RateLimitError` is thrown.
