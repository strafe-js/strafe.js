---
title: CLI Tool (create-strafebot)
description: Scaffold new Strafe Chat bot projects and generate typed command modules from the terminal.
---

`create-strafebot` is an interactive command-line tool that scaffolds a complete TypeScript bot project and generates individual command files inside existing projects.

## Scaffolding a New Bot Project

<Tabs items={['npm', 'npx', 'pnpm', 'bun']}>
  <Tab value="npm">
    ```bash title="Terminal"
    npm create strafebot@latest my-bot
    ```
  </Tab>
  <Tab value="npx">
    ```bash title="Terminal"
    npx create-strafebot my-bot
    ```
  </Tab>
  <Tab value="pnpm">
    ```bash title="Terminal"
    pnpm create strafebot my-bot
    ```
  </Tab>
  <Tab value="bun">
    ```bash title="Terminal"
    bun create strafebot my-bot
    ```
  </Tab>
</Tabs>

## Generating Command Modules

Inside an existing bot project, use the `command` (or `cmd` / `g`) subcommand to generate a new command file in `src/commands/<name>.ts`:

```bash title="Terminal"
# Generate a standard user command
npx create-strafebot command userinfo

# Generate a moderator command (pre-configured with KickMembers, ManageMessages)
npx create-strafebot command warn --mod

# Generate an administrator command (pre-configured with Administrator, BanMembers)
npx create-strafebot command purge --admin
```
